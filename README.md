# Japanese food quiz

A beginner friendly 3 page interactive Japanese food quiz built for hack club ysws Bento.

[Play this quiz here](https://ggpogy123.github.io/bento-website-quiz/)

---

## Features
- **3 Pages**
    - `index.html`: Welcome screen with instructions and start button.
    - `quiz.html`: The main 10 question quiz.
    - `results.html`:Displays final score and high score leaderboard.
- **Navbar**
- **Randomised questions and options**
- **Timed questions**
- **Score Persistance**
- **Leaderboard**
- **Immediate marked option validation**
- **Mobile support**
